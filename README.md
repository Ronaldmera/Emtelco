# 💻 AdminE-Emtelco

AdminE es un sistema diseñado para automatizar y unificar registros provenientes de múltiples archivos Excel, facilitando su procesamiento según la selección del usuario. Su objetivo principal es optimizar tareas repetitivas y mejorar la eficiencia en el manejo de datos.

#### 📌 Características Principales

- Integración de múltiples archivos Excel en un solo flujo de trabajo.
- Selección dinámica de archivos y procesamiento según criterios definidos.
- Reducción de carga operativa manual.
